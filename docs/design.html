Mini Agent OS · design document

One small operating system, any agent, any machine

The same 15-file workspace lands on any machine you work from — a client laptop running Copilot, a workstation running Claude Code or Codex, your own hardware. Self-contained, single-domain, plain markdown. It never phones home; you decide what leaves, and you carry it by hand.

Three folders, three verbs

if you remember nothing else, remember this row

journal/ — what happened

Append-only, one file per day. Session summaries, meeting summaries, decisions. The narrative — short enough to reread.

wiki/ — what we know

Edited in place, few pages, linked. The current state of understanding. When a source changes what you know, this is what gets updated.

wiki/sources/ — what was said

Immutable, verbatim, dated. Raw transcripts and dropped documents. Never edited, only referenced.

AGENTS.md +
copilot-instr.The adapters — the only harness-specific files. Both are 4 lines pointing at context/operating.md. Swap agents, swap nothing else.
context/The constitution. Write rules (titles ≤80 chars as claims), the what-goes-where table, and the three routines. Every agent session loads this first.
projects/One dir per work thread. STATUS.md is deliberately tiny: state, exactly one next action, a two-sentence resume note for picking it up cold.
skills/Portable capabilities in SKILL.md format — frontmatter plus instructions any agent can follow. A skill written once runs under Copilot, Codex, or Claude.
outbox/The one door out. The shutdown routine writes export-YYYY-MM-DD.md here; you carry it by hand. No daemons, no API keys, no sync software.

So the journal is not where transcripts go — it's where their summaries go. A transcript lands verbatim in sources/; the agent digests it; the digest becomes a ## Meeting block in today's journal; and if it changed what you know, a wiki page gets updated. Three layers, one motion.

Follow one transcript through

the same path every input takes
1 · Drop. Save the call transcript to wiki/sources/transcripts/2026-09-06-pricing-review.md. That's the only manual step.
2 · Digest. Ask the agent to process it (or it happens at shutdown): summary + decisions + action items → journal/2026-09-06.md ## Meeting
3 · Synthesize. If it changed the state of play: wiki/pricing-model.md updated, wiki/index.md + log.md touched.
4 · Export. Shutdown bundles the journal entry + changed wiki pages → outbox/export-2026-09-06.md. You carry it out by hand.
5 · Optional hub ingest. If you keep a personal knowledge system elsewhere, it ingests the bundle on its side — stamping its own metadata, merging wiki deltas, updating its boards. The raw transcript never left the machine it was made on; only its distillation did.

The three routines

no cron, no background jobs — you trigger, the agent executes

warmup day start

Load operating.md + STATUS.md of today's projects + anything in wiki/inbox/. ~30 seconds, and the agent knows where you left off.

shutdown day end

Sessions → journal entry → wiki deltas → STATUS.md next-actions → export bundle → and it drafts your team standup from the same material. The discipline pays for itself. ~2 min.

consolidate weekly

Wiki lint: merge duplicate pages, refresh the index, triage inbox/, flag stale claims. Keeps the wiki small enough to stay true.

The confidentiality rules

what makes this safe on client and employer machines
01Nothing references the outside. No external paths, no other client's name, no personal credentials, no tooling beyond the editor and its agent.
02You are the transport. No sync daemons, no API calls to personal services. The export bundle moves when you move it, however the machine's rules allow.
03One domain per workspace. Each machine's workspace knows only its own client's work. Cross-client synthesis, if you do it at all, happens on your own hardware.
04It reads as dev hygiene. A journal, a wiki, per-project status files, an end-of-day summary that becomes your standup — a disciplined engineer's notes, because that's what it is.

Quick start

Direct: cp -r template ~/work && code ~/work — Copilot picks up .github/copilot-instructions.md; Claude Code / Codex read AGENTS.md. Say "run warmup."

Portable: python3 scripts/make_workspace.py --title "Acme DS" --zip → carry dist/workspace-<date>.zip to the target machine, unzip as ~/work.

First real test: drop one transcript in, run shutdown, and read the export bundle it produces.
